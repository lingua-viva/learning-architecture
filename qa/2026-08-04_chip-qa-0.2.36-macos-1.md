## 2. Executive summary
Core teacher flows that don't need voice or Drive **work and behave honestly** — typed observations, lesson-materials generation (privacy-clean, no invention), parent reports (safety gate fires, honestly hedged), archive, and graceful Ollama-down/​recovery. But several **day-one-visible P1s** landed: **voice is completely dead** (a signing-entitlement bug blocks the mic), a **scary error banner shows on every screen** (a missing Python dependency), the app **invents proficiency levels inconsistently**, and **you cannot ask a grounded question about any specific student** (Ask refuses every student-named query). One 0.2.32 regression came back (F6, bundle writes).

**P0: 0 · P1: 5 · P2: 4 · Known-gaps confirmed: 3**

### Is this app ready for teachers tomorrow? **No.**
The engine is sound and the privacy/honesty behavior is genuinely good, but a teacher hits the mic failure, the persistent red error banner, and the "can't ask about my student" wall within the first few minutes. Fix the five P1s (especially the mic entitlement and the `jsonschema` dependency) and it's close.

## 4. Findings by severity

**P1 (fix before teacher rollout):**
1. **T5 — Voice/mic dead (macOS).** Info.plist has `NSMicrophoneUsageDescription`, but signing **entitlements lack `com.apple.security.device.audio-input`**. Under hardened runtime the OS blocks the mic regardless of user permission → no orange dot, silent capture, "I did not hear words." Server STT + PyAV opus decode both proven healthy. **Fix:** add `com.apple.security.device.audio-input` (and `.device.microphone`) to signing entitlements, re-sign, re-notarize.
2. **B4 — Global "Something went wrong" banner.** `/api/sync/status` → 500 `ModuleNotFoundError: No module named 'jsonschema'` (chain: `docpipe/sync.py → vault.py → validate.py`). `jsonschema` is not in the packaged app's deps. Banner persists across **every** view; Sync section stuck "Checking sync queue…". **Blast radius:** any `docpipe` import path (Drive sync/vault/validate). **Fix:** ship `jsonschema` in the installer deps (same class as LV-5).
3. **A4 — Inconsistent invented proficiency.** Untyped observations sometimes get a fabricated `cefr_level_observed`/`sel_valence`, sometimes stay `None`. Puts unfounded proficiency data into a child's record. **Fix:** untyped save must stay "General"; decide what the default type is and stop the classifier assigning a level with no basis.
4. **F6 — Bundle-write regression.** App writes `.pyc` into `Contents/Resources/app/**/__pycache__/` at runtime, breaking the notarization seal (`spctl: a sealed resource is missing or invalid`). Pristine DMG seal is clean → confirmed runtime, not install. **Fix:** set `PYTHONDONTWRITEBYTECODE=1` or point `PYTHONPYCACHEPREFIX` outside the bundle (regression of `e174f53`).
5. **F3 / cross-cutting — no grounded student Q&A.** The Ask PII gate refuses **every** student-named query (before routing, even local). So F2, F3, and checks 18/22 via Ask all refuse. A teacher cannot ask "what support does Marco need?" and get a grounded answer. **Decide:** where should student-specific grounded reasoning live? Right now there is no working surface for it.

**P2 / papercuts:** two Google Drive sections on Sources (tester-confirmed confusing); C7 double-save duplicates (known); parent-report generic opener even at zero data; Rime unconfigured → robotic fallback voice (setup item, not a bug).

**Known-gaps confirmed (not new):** C6 (parent citation generic, not obs ids), C7 (double-save 2 records), C8 (materials — actually **passed** this run, no timeout).

**Environment (not app bugs, but they gate features):** Perplexity/web-search **not configured** (general Ask + Italian-voice test unavailable); Google Drive **not configured** (Drive connect/import untestable); Rime TTS **not configured**.
