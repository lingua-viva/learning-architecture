### Printable Lesson Packet

Added a teacher-facing packet flow so tiered material generation can become an actual classroom artifact.

New endpoints:

- `POST /api/lesson-materials/packet/preview`
- `POST /api/lesson-materials/packet/approve`

Prepare UI now supports:

- Preview Printable Packet
- Review full Markdown before writing anything
- Approve Local Packet
- Show approved local file path and packet content

Packet structure:

- `# Printable Lesson Packet - {topic}`
- Teacher cover page
- Distribution notes per tier
- Review checklist
- Three student handout sections:
  - Foundational Practice
  - Core Practice
  - Extension Practice
- Each handout includes:
  - Learning Goal
  - Instructions
  - Activity
  - Support, when present
  - Exit Ticket

Safety/quality checks:

- Rejects internal or placeholder language such as `RTI`, `diagnostic`, `generated by AI`, `student_ids`, and bracket placeholders.
- Requires exactly three student handout sections.
- Requires Activity and Exit Ticket sections.
- Approved packets are written as private local `.md` files.
- Approved packets create:
  - `DeliverableRecord` with type `lesson_material_packet`
  - Audit receipt with `lesson_material_packet` treated as a local-evidence scope
