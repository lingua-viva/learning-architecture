## Objective

Complete this workflow:

```text
student observation evidence -> teacher decision -> draft artifact -> teacher approval -> deliverable + audit receipt
```

Build deterministic local preview/approval flows for:

- differentiated help artifacts;
- portfolio entry drafts.

This is not an AI generation project. It is a local workflow and governance build.

## Hard Rules

1. **Do not commit.**
2. **Do not call external LLMs or any network service.**
3. **Do not auto-send anything to parents, Drive, Slack, or public surfaces.**
4. **Do not mutate the student lens during preview.**
5. **Do not change RTI tier automatically.**
6. **Do not put raw observation transcript in student-facing artifact text.**
7. **Do not include RTI tier numbers, clinical/diagnostic labels, refugee/trauma labels, or AI attribution in generated student-facing text.**
8. **Use `effective_teacher_id()` for teacher-owned routes.**
9. **Keep the native exit gate and publication safety behavior intact.**

```text

```

```text

```

Route requirements:

- Use existing role-gate coverage for `/api/students...`.
- Accept `Request` and call `effective_teacher_id(request, payload_teacher_id)`.
- Preview returns a draft and `requires_teacher_approval: true`.
- Preview does not create deliverables or audit receipts.
- Approval re-runs safety checks on final text.
- Approval creates a `DeliverableRecord`.
- Approval creates an `AuditReceipt`.
- Approval returns approved record, deliverable, and receipt.

If adding routes changes protected files, update route reachability and UI contract as required.

## Step 4: Safety Checks

Before approval, reject text containing:

- student raw transcript copied verbatim;
- `RTI`, `tier 2`, `tier 3`, etc. in student-facing copy;
- `diagnosis`, `disorder`, `refugee`, `trauma survivor`, or similar labels;
- `AI`, `generated by AI`, or attribution wording.

Reuse:

- `src.education.content_differentiator._check_trauma_safety`
- `src.lingua_viva.governance.check_publication_safety`
- existing parent-report safety patterns where appropriate.

Return `400` or `422` with a stable error for unsafe teacher edits.
