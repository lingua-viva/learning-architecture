## 1. Backend — `POST /api/ask` (src/web.py, owned)

New endpoint, fully self-contained in web.py (same file that owns the Rime urllib
helper — established pattern). The pipeline/gateway stub is NOT touched.

Request: `{"question": str, "mode": "summary" | "more", "history": [{"role","content"}...]}`
- `mode` defaults `"summary"`. `history` (optional, ≤6 entries, each ≤4000 chars) is
  the prior Ask exchange so "more" continues in context. History is teacher-visible
  text only; the gate re-scans the ENTIRE outbound payload every call.

Flow, in order (each step before any egress):
1. Validate question non-empty (400 otherwise).
2. **PII egress gate — refusal, never sanitize-and-send:**
   a. Roster read via `_active_student_names()`; unreadable roster → fail closed
      with the refusal (same rule as `/api/voice/tts`).
   b. `detect_student_detailed(payload_text, roster)` over question + history —
      any exact/fuzzy roster hit → REFUSE.
   c. `contains_private_runtime_data(payload_text)` → REFUSE.
   d. On refusal: `log_event("student_name_blocked", query_text=question)`;
      return HTTP 200 `{"type":"ask_refused","refused":true,
      "message": ask_personal_data_refusal_message(), "external_calls":0}`.
      (200 with error-shaped body = the established `/api/query` honesty pattern.)
3. Key resolution: `provider_api_key("perplexity")` (works via providers.json
   entries even though Perplexity isn't in SUPPORTED_PROVIDERS) →
   `os.environ["PERPLEXITY_API_KEY"]`. Missing → HTTP 200
   `{"type":"ask_unavailable","configured":false,"message": ask_not_configured_message()}`.
4. Outbound hygiene: `redact_injection(question)`; final belt-and-braces
   `assert_safe_for_external_output(payload_text)` immediately before the call
   (raises → refusal path, not a 500).
5. Perplexity call (urllib via `asyncio.to_thread`, 30s timeout, model `sonar-pro`):
   - `mode=summary`: system prompt "Answer this teacher's general question in ONE
     concise paragraph." + `max_tokens=220` — the brief's API-level length cap.
   - `mode=more`: history + user turn "Please continue with more detail." +
     `max_tokens=800`.
   - `log_event("external_call_made", query_text=question)` after a successful call.
6. Response: HTTP 200 `{"type":"ask_result","content": str,"citations": [str],
   "model_used":"perplexity/sonar-pro","route":"external","duration_ms": int,
   "more_available": mode=="summary"}`. Whatever Perplexity returns is the content —
   no post-processing layer.
7. Network/HTTP failure → HTTP 200 `{"type":"ask_unavailable","configured":true,
   "message": ask_offline_message()}` — offline is a supported state, no fake answers.
