## Problem

The Lingua Viva gauntlet has 42 tests. 15 are broken (36%). When a third of
the regression suite is red, real regressions hide in the noise. The codebase
has 110+ API routes with zero UI reachability and no mechanical way to find
or fix them. There is no improvement loop — every fix requires a human to
manually identify the problem, write the fix, and hope they didn't break
something else.

Mission Canvas solved this with a 5-station improvement circuit backed by
deterministic eval lanes, a regression fence, and an append-only improvement
journal. This spec adapts that architecture for Lingua Viva.

## Dependency Chain

```
Phase 1: Fix Gauntlet (15 broken tests)     ← blocks everything
     ↓
Phase 2: Build MEASURE (snapshot all evals)  ← needs working gauntlet
     ↓
Phase 3: Build VERIFY (regression fence)     ← needs baseline MEASURE
     ↓
Phase 4: Build ANALYZE + fix-class taxonomy  ← needs MEASURE data
     ↓
Phase 5: Autonomous sweeps                   ← the circuit tells the agent what to do
```

This spec covers Phases 1-4. Phase 5 is operational, not code.

**File:** `src/lingua_viva/improvement.py` (new)

### ImprovementSnapshot

```python
@dataclass
class ImprovementSnapshot:
    timestamp: str           # ISO 8601
    gauntlet_pass: int       # tests passed
    gauntlet_fail: int       # tests failed
    gauntlet_error: int      # collection errors
    gauntlet_total: int      # total tests
    gauntlet_failures: list[dict]  # [{test_id, error_summary}]
    unit_pass: int
    unit_fail: int
    unit_total: int
    unit_failures: list[dict]
    safety_pass: int
    safety_fail: int
    safety_checks: list[str]  # which safety tests ran
    schema_version_ok: bool
    snapshot_hash: str        # SHA256 of the snapshot itself
```

### CLI

```bash

lv improve --measure    # Run MEASURE only, persist snapshot
lv improve --verify     # Re-run MEASURE, diff against baseline, report regressions
```

**Implementation:** Shell out to `python3 -m pytest` with `--json-report` or

## Phase 3: Build VERIFY

VERIFY re-runs MEASURE and compares against the persisted baseline.

**File:** `src/lingua_viva/improvement.py` (same file)

### Regression Detection

```python
def snapshot_regressions(before: ImprovementSnapshot, after: ImprovementSnapshot) -> list[str]:
    """Return list of regressions. Empty list = no regression."""
    regressions = []
    if after.gauntlet_fail > before.gauntlet_fail:
        # Find which tests newly failed
        before_fails = {f["test_id"] for f in before.gauntlet_failures}
        new_fails = [f for f in after.gauntlet_failures if f["test_id"] not in before_fails]
        for f in new_fails:
            regressions.append(f"GAUNTLET REGRESSION: {f['test_id']} — {f['error_summary']}")
    if after.unit_fail > before.unit_fail:
        before_fails = {f["test_id"] for f in before.unit_failures}
        new_fails = [f for f in after.unit_failures if f["test_id"] not in before_fails]
        for f in new_fails:
            regressions.append(f"UNIT REGRESSION: {f['test_id']} — {f['error_summary']}")
    if after.safety_fail > before.safety_fail:
        regressions.append("SAFETY REGRESSION: safety test count decreased")
    return regressions
```

### VERIFY Flow

1. Load baseline from `~/.lingua-viva/improvement/baseline.json`
2. Run MEASURE (fresh snapshot)
3. Call `snapshot_regressions(baseline, fresh)`
4. If regressions: print them, exit 1
5. If no regressions: print improvement delta, exit 0
6. Persist fresh snapshot as new baseline
7. Append journal entry

## Phase 4: Build ANALYZE + Fix-Class Taxonomy

### Fix Classes (LV-specific)

| Fix Class | Description | Files Touched |
|-----------|-------------|---------------|
| `fix_missing_function` | Implement a function that tests expect but doesn't exist | src/ |
| `fix_missing_fixture` | Create test fixture file that tests reference | tests/fixtures/ |
| `fix_broken_import` | Fix import statement referencing moved/renamed symbol | tests/ |
| `fix_unwired_route` | Add fetch() call in UI for existing API route | static/index.html |
| `mark_internal_route` | Add `# internal-only` comment to route not meant for UI | src/web.py |
| `fix_safety_gap` | Add missing safety check in a new code path | src/ |
| `fix_stale_test` | Update test to match refactored API/function signature | tests/ |
| `add_test_coverage` | Add tests for untested code path | tests/ |

### ANALYZE

```python
def analyze(snapshot: ImprovementSnapshot) -> list[dict]:
    """Rank weaknesses by leverage. Returns ordered list of proposals."""
    weaknesses = []

    # Priority 1: Gauntlet failures (BLOCKER)
    for failure in snapshot.gauntlet_failures:
        weaknesses.append({
            "priority": 1,
            "signal": f"gauntlet_failure:{failure['test_id']}",
            "fix_class": _classify_failure(failure),
            "evidence": failure["error_summary"],
        })

    # Priority 2: Safety failures
    if snapshot.safety_fail > 0:
        weaknesses.append({
            "priority": 2,
            "signal": "safety_regression",
            "fix_class": "fix_safety_gap",
            "evidence": f"{snapshot.safety_fail} safety tests failing",
        })

    # Priority 3: Unit test failures
    for failure in snapshot.unit_failures:
        weaknesses.append({
            "priority": 3,
            "signal": f"unit_failure:{failure['test_id']}",
            "fix_class": _classify_failure(failure),
            "evidence": failure["error_summary"],
        })

    return sorted(weaknesses, key=lambda w: w["priority"])
```

## Non-Goals

- External model calls (improvement circuit is pure local computation)
- Automatic fix execution without operator approval (Phase 5)
- Ontology/canvas/knowledge architecture (LV doesn't have MC's ontology)
- Provider fallback ladder (LV uses local Ollama only)
- Multi-model routing (single model, local)

## Success Criteria

1. Gauntlet: 42/42 pass
2. `lv improve --measure` produces a clean snapshot
3. `lv improve --verify` exits 0 (no regressions)
4. `lv improve` prints the top weakness with a fix_class
5. Improvement journal persists across sessions
